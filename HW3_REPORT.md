#### Описание ошибки
Во-первых упомяну, что на некоторых коммитах после pull request в main видел ошибки в ruff, так как забывал сначала чекнуть им локально. (примеры таких PR - https://github.com/Fetis789/BankMarketingPetModel/pull/24, https://github.com/Fetis789/BankMarketingPetModel/pull/21)

Теперь про ошибку, которая возникла после написания train.py, model_store.py и прогоне тестов на работу сервера. Вот ее скрин:
![Скрин основной ошибки](images/homework3/metadata_feature_names_mistake.png)

Возникла она из-за того, что у меня есть отдельная функция preprocess, которая принимает аргументы в виде значений словаря из metadata с севера с определенными значениями ключей ('feature_names', 'categorical_features' и т.д.). А я, когда писал логирование в ml_flow (и соответсвенно, брал из него логи лучшей модели в метедату сервера), некоторые из этих ключей либо не добавил, либо добавил с другим названием. В итоге изменил логирование и добавил нужные ключи (вот в этом коммите - https://github.com/Fetis789/BankMarketingPetModel/tree/bc890494ff7d815f26b39d16571b67dc4a2babe8). После этого натренил с новым логированием новую модель и там уже чемпионом сделал последнюю версию. Скрин уже прикреплял выше.
